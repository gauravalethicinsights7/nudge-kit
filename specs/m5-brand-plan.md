# Spec M5 — Brand plan

## Goal
Assemble a brand plan from approved M1–M4 objects, where every element traces to evidence and every number to a model.

## Inputs
Approved `MarketLandscape`, `Segment[]`, `Persona[]`, `JourneyMap[]`, `Competitor[]`, `MessageMap`; user inputs: revenue ambition, budget envelope, net price, plan horizon (default 12 months).

## Output: `BrandPlan`
| Section | Fields | Generated by |
|---|---|---|
| situation | summary, key_facts[] (evidence_ids) | LLM from landscape |
| key_issues | [{statement, barrier, segment_id, revenue_at_stake, evidence_ids}] (4–6) | `models/plan.py` ranks; LLM words |
| imperatives | [{title, key_issue_ids[], segment_id, from_rung, to_rung}] (3–5) | LLM, constrained to key issues |
| positioning | {target, frame_of_reference, point_of_difference, reasons_to_believe[evidence_ids]} | LLM; POD must be in MessageMap.whitespace ∩ brand evidence |
| message_house | {core, pillars[{driver, message, proofs[evidence_ids]}] (3), by_persona{persona_id: emphasis}} | LLM |
| objectives | [{imperative_id, metric, baseline, target, due, segment_id}] | `models/forecast.py` sizes; LLM phrases |
| strategies_tactics | per imperative: segments, messages, channel sequence ref, content needs | LLM; channel refs filled after M6 |
| kpi_tree | leading[] → lagging[] with targets | template + forecast |
| forecast | scenarios{base, upside, downside}: {delta_nrx, revenue, roi, assumptions[{name, value, confidence}]} | `models/forecast.py` |
| budget | by imperative and channel | from M6 (placeholder until run) |
| risks_tests | [{assumption, confidence, test_design, stop_go}] | lowest-confidence assumptions |
| compliance_flags | [{item, rule_id, severity}] | guardrail check |

## Models
```
revenue_at_stake(issue) = segment.total_potential * (target_share - avg_share) * net_price
delta_nrx_s = N_s * sum_k(delta_p_s,k * new_patients_s,k) * persistence_s
revenue = delta_nrx * net_price ; roi = (revenue * margin - incremental_spend) / incremental_spend
scenarios: base = priors; upside/downside = ±1 sd on the 3 highest-sensitivity assumptions (tornado in models/forecast.py)
```

## Quality bar (deterministic + rubric)
- Every imperative links ≥ 1 key issue; every key issue has revenue_at_stake.
- Every pillar has a driver in persona top-3 and ≥ 1 proof evidence_id (mlr_status noted).
- Every objective has baseline, target, due date.
- Forecast lists its 3 largest-sensitivity assumptions with confidence.
- POD ∈ whitespace.
- Compliance guardrail returns no `severity=block` items.

## Export
`BrandPlan` → Markdown and DOCX (python-docx) via `exporters/brand_plan.py`.
